# Mission 1 — Know Your Computer

### Task 1.1 — Trace one activity using IPOS

**Activity chosen: Typing and saving a document using a computer.**

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| Input | I type text using the keyboard and give commands using the trackpad. | Keyboard and trackpad |
| Processing | The computer processes the entered text and commands using the CPU and temporarily holds data in RAM. | CPU and RAM |
| Output | The typed text appears on the screen so I can view and edit it. | Monitor / Display |
| Storage | When I save the document, the file is stored on the computer for future use. | SSD |

**Explanation:**

When I type a document, the keyboard sends input to the computer. The CPU processes the instructions and RAM temporarily holds the information while I work. The screen displays the document as output. Finally, when I save the file, it is stored on the SSD so that I can access it later.

## 4. My understanding

Through this mission, I understood that a computer works through four major stages known as IPOS: Input, Processing, Output and Storage.

I also learned the difference between hardware and software. Hardware refers to the physical components of a computer that we can touch, while software consists of programs and instructions that tell the hardware what to do.

I understood that computer-based systems are used in many everyday activities, including banking, traffic management and entertainment.
