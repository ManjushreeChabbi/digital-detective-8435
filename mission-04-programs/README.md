### Task 4.2 — Compare compiler and interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation / execution happens | Translates source code before execution. | Executes instructions at runtime. |
| Typical output | Often produces an executable or another translated form. | Commonly executes through an interpreter runtime. |
| One example | GCC for C programs. | Python interpreter. |
| One advantage | Can produce efficient executable programs. | Makes testing and running code convenient. |

**Explanation:**

A compiler translates source code into another form before the program runs. An interpreter executes instructions at runtime.

A compiler often produces a separate executable file, whereas an interpreter commonly runs the program through its runtime environment. Some programming language implementations combine both approaches.
